One sentence explaining the modern internet to a time traveler from 1800 — built only from things they already know: a road, a post office, a library, a letter, ink, supper.

> It is one road joining every post office and library on earth, so a letter reaches the far side of the world before your ink dries, and a stranger a thousand miles away can answer you before supper.

198 characters, one sentence. No word coined after 1800; the network is a road, messages are letters that arrive before the ink dries, and asking the world is a stranger answering before supper.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is deterministic: it always writes the same single sentence (198 characters) to `/output/entry.txt`. No input, no network, no randomness.
